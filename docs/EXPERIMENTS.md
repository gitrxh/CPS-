# 实验协议与记录

本文件整理截至 2026-10-14 已经保存的配置、采集完成审查和诊断结果。第 1–6 阶段完成，诊断训练门槛未通过，本轮未训练、未进行 held-out 评估。当前主方案是 [recovery_projection_candidate_v2.json](../configs/recovery_projection_candidate_v2.json)。[research_design.json](../research_design.json) 记录较早的研究设计，不代表当前所有阶段均已获准执行。

## 研究问题与解释范围

当前实验检验：在同一冻结学习者实际访问的历史上，从同一有限、专家可恢复动作集合中，按该学习者的动作概率选择标签，是否比普通专家恢复与均匀动作选择更有利于真实续行及后续任务成功。

这是单轮、有限池、学习者状态上的局部动作选择实验。普通专家恢复提供一轮 DAgger 式对照。当前方案没有检验完整迭代 DAgger、完整路径空间 ECPS/MH、MH 平稳性或全局最优性，也没有建立方法新颖性。调研报告是研究资料，不提供执行权限或已经成立的效果结论。

### 数据与锚点

采集任务来自冻结 `train120` 与此前 same60 训练任务的有序差集：每类 10 个，共 60 个。这些任务没有进入所选 same60 canonical adapter 的 SFT 数据，但仍是训练任务，不是 held-out 证据。

每个任务只采集一次原始学习者执行轨迹。分别记录第 4、8、16 个真实动作后的状态，构成 180 个固定锚点槽位。已终止、无可用动作或其他结构性不可用槽位须明确记录，不替换任务或时间点。提示保留原任务文本、实际历史（包括错误动作）、当前观察与可执行命令。

独立的新 `valid_seen` 评估集固定为每类 8 个、共 48 个任务。它按元数据和哈希顺序选取，排除已经评估过的任务及其相同语义配方，再冻结游戏和元数据哈希。新 seen 任务不等于未见房间泛化。`unseen134` 未用于本轮评估，也不能用于挽救失败筛查。

### 候选认证与回放

每个可用锚点最多提出 8 个不同首动作：首先包括原生规划器首动作；再包括与其不同、可执行且非纯信息动作的冻结学习者下一动作；剩余名额按固定哈希顺序从可执行命令填充。概率和下游成功率都不能用来挑选提案集合或扩充低产出的池。

每次分支独立重置，重放学习者的真实前缀并核对状态，再执行候选首动作，随后由原生规划器从其真实后继状态继续。在原始总计 100 动作预算内达成 `won=true` 的动作才获得可恢复证书。规划器基准首动作也必须有成功证书，该锚点才可供三组共同使用。

所有变化动作及后续观察都由真实模拟器产生，禁止接回旧的反事实后缀。第 4 阶段再次独立重置并重放前缀和候选首动作，比较其真实下一状态与观察。任何不一致均导致停止。

### 条件分布与三组标签

对某个历史 `h`，设冻结的、经规划器认证的有限动作集合为 `C_h`：

```text
q(a | h) = exp(log pi_BC(a + EOS | h))
           / sum_{b in C_h} exp(log pi_BC(b + EOS | h))
```

温度固定为 1，不做长度归一化、裁剪、温度搜索或贪心替换。该分布只在已提出且认证的有限支持上归一化，不等于成功路径条件分布的首动作边缘。

| 训练臂 | 同一可用锚点上的标签 |
| --- | --- |
| `expert_recovery` | 原生规划器首动作 |
| `uniform_viable_recovery` | 在 `C_h` 中均匀抽取一次 |
| `reference_conditional_recovery` | 从 `q` 抽取一次 |

抽样使用预先固定的哈希盐和 CDF 顺序，记录抽样值，不重抽。三份数据须在查看真实续行结果前冻结。学生只能看到原任务、实际历史、当前观察、可执行命令与所选动作目标；教师计划、未来观察、状态事实、成功标签、概率与 Q 值均不得进入提示。

### 固定 36 槽位的诊断门槛

每类选择 6 个不同训练任务：2 个使用第 4 步锚点，2 个使用第 8 步，2 个使用第 16 步。身份与时间点在执行前按哈希规则固定，不替换不可用锚点。

对每个可用锚点中的每个认证动作，重新执行前缀与首动作，然后让冻结学习者贪心续行。`Q_h(a)` 为这次真实执行的任务成败，不能用规划器成功、NLL 或价值模型预测替代。最多执行 288 个学习者分支。

定义 `Vq = sum_a q(a) Q_h(a)`、`Vu = mean_a Q_h(a)`、`Ve = Q_h(规划器首动作)`。继续训练必须同时满足：

1. 至少 12/36 个锚点有两个或更多认证动作，覆盖至少四类任务。
2. 至少八个诊断锚点同时具有学习者续行成功与失败的候选。
3. 固定 36 槽位上 `mean(Vq - Vu) >= 2/36`。
4. 固定 36 槽位上 `mean(Vq - Ve) >= 0`。
5. 冻结条件标签相对专家标签、均匀标签分别至少在 12 个可用训练锚点上不同。
6. 所有计划技术记录完整，回放、提示、哈希和 token 检查无错误。

结构性不可用槽位保留 `Q=null`，对固定分母上的成对干预差值贡献 0；这不表示实际观察到一次任务失败。异常、缺失分支、预算中止等技术缺失则令 `gate=null`、`complete=false`，不能按结构性零值补齐，也不能根据已完成前缀判断通过。

这些是预登记的机制与停止门槛，不是显著性检验。科学门槛失败即停止本版本，不降低阈值、不换子集、不重抽标签、不调整温度或种子。门槛通过也不代表 held-out 效果成立。

### 训练与最终比较

三组从同一 canonical LoRA 权重继续训练，使用新的相同 AdamW 状态，不堆叠新 adapter，也不复用旧优化器状态。每组固定 100 个更新；batch size 为 1，梯度累积为 8。每次更新交替使用四个共同原始 BC 样本和四个共同恢复锚点，每组累计 400 次 BC 与 400 次恢复暴露。样本索引计划在三组间相同。

学习率为 `2e-4`，LoRA rank/alpha/dropout 为 `16/32/0.05`，bfloat16，weight decay 为 0，梯度裁剪为 1，采用动作 token 加权损失。目标 token 数允许不同，但必须记录；相同更新数不代表相同总计算量。只使用最终 step 100 检查点，三个模型全部锁定后才能进行评估。

评估顺序固定为冻结 canonical BC、均匀恢复、专家恢复、条件恢复；四个模型各执行同一 48 个新 seen 任务。完整 192 次结果锁定后，主要比较条件恢复相对专家恢复的配对任务成功差，均匀恢复也是必须通过的对照。

预设实用筛查要求：条件恢复相对两个同预算恢复对照分别至少增加 3/48 个成功任务，并且严格超过冻结 BC。须报告四组总数、完整配对表、增益/损失、六类任务和各场景的分母。单个种子与相关场景任务不支持独立样本显著性或普遍泛化结论。若恢复方法仅共同超过冻结 BC，不能据此认定条件选择有效。

## 预算与恢复边界

| 阶段 | 最大开始执行的环境步数 | 阶段时间上限 |
| --- | ---: | ---: |
| 采集 | 6,000 | 7,200 秒 |
| Oracle，包含前缀 | 144,000 | 43,200 秒 |
| 独立回放 | 24,480 | 7,200 秒 |
| 学习者续行诊断，包含前缀 | 28,800 | 21,600 秒 |
| 四组 held-out 评估合计 | 19,200 | 每模型 7,200 秒 |

主实验环境步数硬上限为 224,000，重置上限为 3,600，生成 token 上限为 4,000,000；全局时间上限为 171,840 秒，包含等待、验证和清理。评分与每个训练作业各有 7,200 秒上限，仍受剩余全局时间约束。完整预算还包含评分、训练 token 及独立前期 smoke 成本，详见候选配置的 `finite_budgets`。

执行链经历原始采集、首次中断恢复 `resume1` 和服务器重启后的 `reboot_v2`。各阶段继承历史记录与成本，不退还中断工作。两次历史环境 step 已发起但返回结果未持久确认，最终账本保留两笔 unknown step 差额，不能伪造为已完成交互。

首次恢复保留原始绝对截止时间。服务器重启后的恢复曾单独增加一个 12 小时 Oracle 时间窗口；**原始全局截止时间与全局预算仍保留**，不能把该恢复描述为所有阶段截止时间均未变化。采集完成审查通过后，另行冻结的诊断执行采用仅进入评分与真实续行诊断，没有自动进入训练或评估。

诊断结束时累计环境步数为 47,002 次发起、47,000 次完成，重置 2,378 次；其中本次诊断执行 17,350 个环境步、230 次重置与 15,072 次学习者生成调用。两步差额均继承自历史中断。历史执行时长的观察值与上界分别保留，不据此声称精确的合计计算时间。

第二轮三组各执行同一 24 个开发任务，共 72 次评估，训练种子为 42，每组 100 个更新。完整审查核对了真实轨迹连续性、环境成功标志与汇总数，记录的技术错误为 0。Reference 对 Canonical 的配对比较为 0 个增益、8 个损失；对 Uniform 为 3 个增益、5 个损失。

数据审计未发现跨组任务文本、初始输入或因果前缀混杂；因此该结果应按现有方法负结果保留。它也不证明所有条件选择方法均无效，不能把两轮不同设定合并成一个效应估计。旧确认候选没有获准启动，不能通过补种子、换温度或打开 unseen 集来挽救。

本轮真实规划器 smoke 检查已通过：账本重算得到 46 次重置、320 个环境步。审查包含 18 个扰动案例，17 个成功、1 个按固定规则不适用，并核对原始轨迹和无专家回放。这只验证接口与执行可行性，不能证明学习者收益。

## 本轮诊断结果（2026-10-14）

采集、Oracle 和独立回放的完整记录分别为 60、180、180 条，采集完成独立审查通过。评分覆盖全部 180 个固定槽位，其中 131 个可用、49 个结构性不可用；三组标签在真实续行结果揭盲前锁定。采集原始学习者成功 26/60 次、记录 2,701 个不可执行动作，Oracle 有 1 个提案未获认证。这些均为训练任务上的描述性结果。

固定 36 槽位诊断中，29 个锚点可用并覆盖六类任务，共执行 230 个真实学习者分支；7 个槽位在锚点前已终止。`complete=true`、`gate_evaluable=true`、`training_gate_passed=false`。以下两种分母回答不同问题，不能混用：

| 指标 | 分母 | 结果 | 解释 |
| --- | ---: | ---: | --- |
| 平均 Vq | 29 个可用锚点 | 37.6473% | 条件动作分布加权的真实续行成功 |
| 平均 Vu | 29 个可用锚点 | 31.0345% | 同一候选池均匀加权的真实续行成功 |
| 平均 Ve | 29 个可用锚点 | 79.3103% | 专家首动作后由冻结学习者续行 |
| mean(Vq − Vu) | 固定 36 槽位 | +5.32698 个百分点 | 低于 2/36（5.55556 个百分点），未通过 |
| mean(Vq − Ve) | 固定 36 槽位 | −33.56190 个百分点 | 低于 0，未通过 |

覆盖、真实 Q 差异和标签非退化门槛通过：29 个多动作锚点覆盖六类任务，21 个锚点同时有成功与失败候选，条件标签与专家／均匀标签分别在 96／116 个可用训练锚点上不同。但两个收益比较门槛均未通过，故本版本停止，未执行第 7 阶段训练、第 8 阶段 held-out 评估或 unseen 评估。

描述性拆分为：21 个 mixed-Q 锚点、4 个候选全失败锚点、4 个候选全成功锚点，以及 7 个不可用槽位。该拆分只帮助解释结果，不重新挑选子集或修改门槛。7 个不可用槽位的 `Q/Vq/Vu/Ve` 均为 `null`，仅在预设固定分母差值中贡献 0，不是七次观察到的失败。该结果支持停止当前版本；它没有检验本轮恢复训练的收益，也不能概括为整个条件选择方向被否定。

本轮加入重启执行链适配、诊断控制器与入口脚本，部署采用记录冻结 59 个源码文件；33 项适配与诊断测试在本地和部署环境通过。源码适配审查与采集完成审查均已通过。队列在 2026-10-14 14:47（北京时间）记录两阶段正常完成、清理完成，停在 `needs_astra_diagnostic_review`。发布检查仅确认摘要一致性、诊断文件哈希与门槛重算；完整诊断结束后的全部哈希独立审查尚未完成，不能把源码或采集审查扩写为整轮诊断审查通过。
